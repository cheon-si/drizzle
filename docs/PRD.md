# 슬비의 카페 지도 — PRD v0.2

v0.1 대비 변경점만 적는다. 나머지 요구사항(F1~F8, 화면 구조, 디자인 방향)은 v0.1 그대로.

## 결정 사항 (v0.1 → v0.2)

| 항목 | v0.1 | v0.2 | 이유 |
|---|---|---|---|
| DB | Supabase | **Neon Postgres + Drizzle ORM** | Vercel 마켓플레이스 원클릭, 카드 불필요. Supabase 무료 티어의 "1주 미사용 시 일시정지" 리스크 제거. 1인 사용량에서 Neon 무료(0.5GB, scale-to-zero)로 충분 |
| 인증 | A/B 택1 | **B안 확정**: 비밀번호 1개 + httpOnly 쿠키 1년 | 슬비 마찰 최소. 개인정보성 데이터 없음 전제 |
| 마이그레이션 | — | `drizzle-kit push` (마이그레이션 파일 없음) | 1인 개발, 스키마 변경 시 push 한 번 |
| 사진(F8) | P2 | **v1 제외**, `notes.photo_url` 컬럼만 유지 | 배포 우선. 필요해지면 Vercel Blob으로 추가 |
| 메모 작성 시 상태 | — | 메모를 남기면 자동으로 `가봄` | 별도 탭 조작 생략 |
| 폰트 | Pretendard/Gowun Dodum | Pretendard Variable (jsdelivr 동적 서브셋) | 번들 무게 0, 한글 가독성 |
| 네이버 딥링크 | 앱 URL Scheme | 웹 URL(`map.naver.com/p/search`) | 모바일에서 네이버가 앱 열기 배너를 자체 제공. Scheme 분기 코드 불필요 |
| 지도 SDK 로드 | 동적 import | `<script>` 수동 삽입 + `autoload=false` | Kakao SDK는 npm 패키지가 아님. 첫 페인트 후 로드 |

## 구현 범위 (이번 배포에 포함)

- F1 검색: 카카오 키워드 검색, `CE7` 필터, 300ms 디바운스, 15건, 지도 중심 좌표 기준 정렬 힌트 전달
- F2 지도: 커스텀 SVG 마커 3종(가고싶음=라떼, 가봄=코랄, 4.5↑=하트 배지), 30개 이상 시 클러스터러, 현재 위치 버튼(거부 시 서울시청)
- F3 저장: `kakao_place_id` 기준 upsert, 상태 토글
- F4 별점: 0.5 단위, 같은 값 재탭 시 해제, 탭 시 pop 애니메이션
- F5 메모: 카페당 여러 개, 1000자, 방문일, 삭제
- F6 리스트: 최신/별점/이름 정렬, 전체/가봄/가고싶음/★4.0+ 필터
- F7 딥링크: 카카오맵(`place_url`), 네이버 지도, 전화
- PWA-lite: manifest + 홈 화면 추가 가능. 서비스워커/오프라인 없음
